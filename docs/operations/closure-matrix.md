# The closure matrix: qualification evidence levels, public (Q39-17 / #336)

A closed GitHub issue is not a proven capability. This page is the
PUBLIC view of [ADR-0033](../adr/0033-execution-ownership-consolidation.md)
§4 (extended by [ADR-0034](../adr/0034-execution-ownership-map.md) —
the ownership map with the verified production callers): for each of
the execution-ownership capabilities (which plan is approved, which
credential, which attempt, which checkpoint, which candidate verified,
which receipt counts, whether an operator amendment applies), the
CURRENT evidence class at each of six closure levels — domain contract,
wired caller, executed process, native execution, cross-process
recovery, customer acceptance.

The evidence classes (no class substitutes for another):

| Class | Meaning |
| --- | --- |
| `unit-proven` | the owner's contract suite pins the decision |
| `pe-proven` | a [production-entry](../../tests/production_entry/README.md) trace drives the same entry a customer invokes (real processes, real restarts, the modeled native surface) |
| `live` | a committed live-provider record proves it against the REAL provider — failures recorded as failures |
| `pending-human` | the evidence chain is complete up to the human record; the approval is the only missing member |
| `pending` | the honest gap; the row names where the gap is documented |

The data lives in `src/forge/adaptive/closure_matrix.py`
(`forge.closure.matrix/1`) and is validated against this repository —
every cited evidence path must exist, so a renamed trace file is a
test failure, never a stale citation. The
[profile-qualification records](../releases/profile-records.md) judge
PROFILES (provider/recipe/harness combinations on a release); this
matrix judges CAPABILITIES (the decisions every execution carries).
The two views join on the live records but answer different questions.

Read plainly today: 28 of 42 cells are proven; every capability
carries at least one pending level, and that is the honest state — the
live interrupt/resume arm is recorded as a FAILED delivery, the live
rebind and grant-redemption traces do not exist yet, and the
usage-identity ladder has rungs left. When a level genuinely closes,
the matrix data changes in the same reviewed change and this page is
regenerated (`ClosureMatrix.render()`).
