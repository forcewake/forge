# Grok Build — retired

Grok Build is not a supported Forge 1.0 lane driver. The old batch recipe,
contrib implementation and activation switch are removed. Existing Grok
credentials or old driver names do not enable a lane or select a fallback.

Choose [Claude Code](claude-code.md) or [Copilot CLI](copilot-cli.md) explicitly
in the repository policy before approval, then follow [onboarding](onboarding.md).
Do not reuse the retired recipe's unattended permissions or secret variables.
