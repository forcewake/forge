# OpenCode — retired

OpenCode is not a supported Forge 1.0 lane driver. The batch recipe, contrib
implementation, alternate server driver and old configuration are removed.
There is no alias, activation flag or automatic fallback.

Choose [Claude Code](claude-code.md) or [Copilot CLI](copilot-cli.md) explicitly
in the repository policy before approval. Follow [onboarding](onboarding.md);
the current lane does not consume the retired recipe's provider keys,
permission maps or MCP environment settings.
